개인정보처리방침

시행일: 2026년 11월 22일 · 큰빛교회 (대한예수교장로회 고신)

큰빛교회(이하 ‘교회’)는 개인정보를 소중히 다룹니다. 이 방침은 ① 교회 홈페이지(https://glc150606.github.io/glc/)와 ② 교회가 내부에서 사용하는 ‘큰빛교회 쇼츠 업로드’ 프로그램에 적용됩니다.

1. 홈페이지에서 수집하는 정보

교회 홈페이지는 교회를 소개하는 안내용 페이지입니다. 회원가입, 로그인, 게시판, 문의 양식이 없으며 방문자의 개인정보를 수집하거나 저장하지 않습니다. 쿠키나 방문자 분석 도구도 사용하지 않습니다.

다만 홈페이지를 보여 주는 과정에서 아래 외부 서비스가 함께 쓰이며, 이 서비스들은 접속에 필요한 기술 정보(접속 주소(IP), 브라우저 종류 등)를 각자의 방침에 따라 처리할 수 있습니다.

  • GitHub Pages — 홈페이지 호스팅
  • Google Fonts — 글꼴 제공
  • 네이버 지도 — ‘오시는 길’ 지도 표시
  • YouTube — 교회 유튜브 채널로 연결되는 링크

2. ‘큰빛교회 쇼츠 업로드’ 프로그램과 Google 사용자 데이터

‘큰빛교회 쇼츠 업로드’는 교회 영상 담당자가 설교 쇼츠 영상을 교회 유튜브 채널에 올리기 위해 사용하는 교회 내부용 프로그램입니다. 일반 방문자나 성도에게 제공되는 서비스가 아니며, 교회 유튜브 채널을 관리하는 담당자만 사용합니다. 이 프로그램은 YouTube API 서비스를 사용합니다.

접근하는 정보

담당자가 Google 로그인 화면에서 직접 동의한 범위 안에서만 아래 정보에 접근합니다.

  • 동의한 Google 계정에 연결된 유튜브 채널에 영상을 올리는 권한
  • 올리는 영상의 제목·설명·공개 범위·썸네일 등 영상 정보를 설정하는 권한
  • 영상을 올릴 채널을 확인하기 위한 채널 기본 정보(채널 이름 등)
  • 위 작업에 필요한 Google 인증 정보(접근 토큰)

이메일 내용, 연락처, 시청 기록 등 위 목적과 관계없는 정보에는 접근하지 않습니다.

이용 목적

접근한 정보는 교회 유튜브 채널에 영상을 올리고 그 영상의 정보를 관리하는 데에만 사용합니다.

보관과 보호

  • Google 인증 정보는 프로그램을 실행하는 교회 영상 작업용 컴퓨터에만 저장하며, 교회는 이를 보관하는 별도의 서버나 데이터베이스를 운영하지 않습니다.
  • 인증 정보는 담당자 외에는 접근할 수 없도록 관리합니다.
  • 권한을 철회하거나 프로그램 사용을 마치면 저장된 인증 정보를 지체 없이 삭제합니다.

제3자 제공

Google 사용자 데이터를 제3자에게 판매·공유·제공하지 않습니다. 광고, 신용 평가, 인공지능 모델 학습 등 다른 목적으로 사용하지 않으며, 법령에 따른 요구가 있는 경우를 제외하고 사람이 열람하지 않습니다.

이 프로그램이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전달하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

이 프로그램은 YouTube API 서비스를 사용하므로, 프로그램 사용자는 YouTube 서비스 약관에 동의하게 되며 Google 개인정보처리방침이 함께 적용됩니다.

권한 철회와 삭제 요청

담당자는 언제든지 Google 계정의 ‘서드 파티 앱 및 서비스’ 설정에서 이 프로그램의 접근 권한을 삭제할 수 있습니다. 교회에 요청하시면 작업용 컴퓨터에 저장된 인증 정보도 바로 삭제합니다.

The tool’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Because the tool uses YouTube API Services, its users agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.

Revoking access. Access can be revoked at any time from the Google Account permissions page. On request, the church will also delete the stored tokens.
